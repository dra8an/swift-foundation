Apple's runtime ICU treats Meiji as starting **1868-09-08** (not the CLDR-canonical 1868-10-23). Other modern era boundaries match the data file. Cause uncertain — likely Apple's bundled compiled `.dat` differs from upstream ICU4C source. Possibly a lunisolar/Gregorian conversion bug stored in their data table.

Our `Calendar_Japanese.swift` uses 1868-09-08 to match Apple's runtime behavior. TODO comment in source flags this for later investigation. See `backup/j1-japanese-suite-a-complete/README.md` § "Open issue" for full forensic notes.

# Part 2 — afternoon continuation (same date)

## Japanese Suites B + C — and the two bugs Suite B caught

- **`JapanesePublicAPIComparisonProbe.swift`** (Suite B, 8 topics) and
  **`JapaneseRecurrenceRuleParityProbe.swift`** (Suite C, 5 generic + 3
  era-transition recurrence tests) added, mirroring the Buddhist pattern.
- Suite B immediately caught **two real bugs** in `Calendar_Japanese.swift`:
  1. **`convertedToGregorian` era inference.** The slow-path
     `_adjustedComponents` (Calendar_Enumerate.swift:693) writes
     `year` (year-in-era) back WITHOUT era; our conversion required BOTH,
     so `{year: 7, month: 12, day: 25}` materialized as year 7 CE →
     `enumerateDates`/`nextDate` returned next-year matches (+1-year-off,
     e.g. Christmas 2026 instead of 2025). Fix: year-without-era defaults
     to the latest era (Reiwa) — matches ICU's no-explicit-era behavior.
  2. **`dateComponents(_:from:to:)` year override.** `japaneseYearDifference`
     forced a raw Gregorian year delta, breaking same-era short spans
     (Nov→Jan 60-day diff said year=1; ICU/correct says 0 with month/day
     remainder). Fix: deleted the override; gregorian's calendar-aware
     diff is correct for the imperial calendar too.
- New documented ICU quirk (excluded from probes):
  `dateInterval(.era).duration` — ICU ends an era's interval at
  `start.month/day` of the NEXT era's start **year** (Heisei "ends"
  2019-01-08 per ICU, not the real 2019-05-01). Ours returns the true
  `[era.start, next.start)` interval.
- Full suite: **1448 tests / 115 suites pass.**
