## ⚠ Known issue — Meiji date discrepancy

Apple's runtime ICU treats Meiji as starting **1868-09-08** (not the CLDR-canonical 1868-10-23). Other modern era boundaries match the data file. Cause uncertain — likely Apple's bundled compiled `.dat` differs from upstream ICU4C source. Possibly a lunisolar/Gregorian conversion bug stored in their data table.

Our `Calendar_Japanese.swift` uses 1868-09-08 to match Apple's runtime behavior. TODO comment in source flags this for later investigation. See `backup/j1-japanese-suite-a-complete/README.md` § "Open issue" for full forensic notes.
